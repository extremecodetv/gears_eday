# ДОЕБАТЬСЯ ДО ХУЙНИ — Gears of War: E-Day (ревью-рандомайзер)

Рандомайзер реальных **негативных обзоров** к **Gears of War: E-Day** из Steam (app `3010850`). Жмёшь кнопку — сверху появляется **смысловой перевод** отзыва, под ним **пруф**: оригинальный комментарий как есть и подпись автора (ник · часы на момент обзора · 👍). База — **145 отзывов** в 9 рубриках, оригиналы на 9 языках: `EN CN TC JP KO PL ES DE FR IT NL`.

Ничего не выдумано: каждую карточку можно перепроверить по ссылке в подвале.

Родоначальник жанра, если что, был такой:

> «И это самое… Когда ждёшь у двери, которую нужно открыть секунд 30 или где-то даже минуту… мммм… 2005 год, охуенно»

## Что внутри

- **`index.html`** — весь сайт: HTML + CSS + JS в одном файле. Ноль зависимостей и ноль сборки, база обзоров внутри — открывается двойным кликом и работает офлайн. Из сети тянется только арт (фон и обложка) с CDN Steam: без интернета страница остаётся тёмной, но полностью рабочей.
- **`validate.cjs`** — тест на Node.js (54 проверки: целостность базы и пруфов, отсутствие дублей и стимовской цензуры `♥♥`, совпадение перевода с оригиналом, ротация без повторов подряд, фильтр по рубрикам, счётчик, вывод и соответствие пруфа, случайность на 500 роллов, разметка, тексты и подвал, арт-фон и обложка со страницы игры в Steam).

### Управление

- **Кнопка «▶ Ещё отзыв»** / `Space` / `→` / `Enter` — следующий отзыв;
- цифры `1`…`9` — переключить рубрику, `0` — вернуть «Всё подряд»;
- **«👁 Оригинал: вкл/выкл»** — показать или спрятать оригинал камента под переводом;
- **«Скопировать»** — перевод вместе с оригиналом и подписью в буфер (с фолбэком через `execCommand`), **«Поделиться»** — системный шейр на мобилке.

## Пруфы и источники

Все отзывы пришли из блока негативных обзоров: <https://steamcommunity.com/app/3010850/negativereviews/> (тот же текст отдаёт JSON-эндпоинт `store.steampowered.com/appreviews/3010850?json=1&review_type=negative&language=...`).

- **Оригинал приводится как есть** — с опечатками, caps и грамматикой автора. Это часть соли, править не надо.
- **Перевод — смысловой**: не подстрочник, а нормальный русский с сохранением смысла. Если автор матерится, перевод тоже.
- Куски отзыва, которые вырезаны из цитаты, помечены `[...]` — так из карточки убраны фрагменты не по теме (например, про повестку), без склейки чужих фраз.
- Оригиналы на русском в базу не брали: там перевод не нужен, а карточка из двух одинаковых строк выглядит глупо.
- Стимовская матерная цензура (`♥♥♥♥`) в базу не попала; звёздочки вида `****` в оригинале — это авторские, их оставили.
- Ники — публичные данные Steam, приведены для указания источника цитаты. Не согласен с формулировкой — жми «Ещё отзыв», там 145 вариантов.

## Арт

Фон страницы и обложка подтянуты прямо с официальной страницы игры в Steam (<https://store.steampowered.com/app/3010850/>). В репозитории картинок нет — грузятся с CDN Steam:

| Где на сайте | Ассет Steam | Вес |
|---|---|---|
| фон всей страницы (`.bg`: `position:fixed` + `background-size:cover`, приглушён фильтром, сверху виньетка) | `store.akamai.steamstatic.com/images/storepagebackground/app/3010850` | ~70 КБ |
| обложка-баннер под шапкой (`.hero`, обрезанные углы как у карточки, снизу подпись `обложка · Steam`) | `shared.akamai.steamstatic.com/store_item_assets/steam/apps/3010850/capsule_616x353.jpg` | ~72 КБ |

- Оба ассета объявлены через `<link rel="preload" as="image">`, чтобы арт не «проявлялся» с задержкой на первом ролле.
- **Без сети ничего не ломается**: фон остаётся тёмным (базовые градиенты в `body`), у обложки есть подложка `var(--panel)`, вся механика рандомайзера, пруфы и клавиатура работают как обычно.
- Хочешь совсем автономный файл — скачай обе картинки рядом с `index.html` и замени в CSS `https://…` на `capsule_616x353.jpg` и `storebg.jpg`.
- Арт — собственность Microsoft / The Coalition / Xbox Game Studios; в репозиторий он не копируется, а берётся с официального CDN. Если правообладатель попросит — убирается удалением двух правил `.bg` и `.hero`.

## Деплой на GitHub Pages

Сайт уже живёт тут: <https://extremecodetv.github.io/gears_eday/> (ветка `main`, папка `/root`).

### Вариант A — через сайт GitHub (без консоли)

1. Заходишь на github.com → **New repository**. Имя любое, например `gears-nagging`. Видимость — **Public** (Pages на бесплатном плане работает только для публичных репозиториев). **Create repository**.
2. **Add file → Upload files** → перетаскиваешь `index.html` (и `README.md`). **Commit changes**.
3. **Settings → Pages** (левое меню, раздел *Code and automation*).
4. **Source: Deploy from a branch** · **Branch: `main`**, папка **`/ (root)`** → **Save**.
5. Ждёшь 1–2 минуты, обновляешь страницу — сверху появится ссылка вида:
   `https://<твой-ник>.github.io/<имя-репозитория>/`
6. Открываешь и жмёшь кнопку. Готово.

### Полезные нюансы

- **`index.html` должен быть в корне** (или в `/docs`, если выбрал такую папку в настройках Pages). Имя файла — строго `index.html`, иначе будет 404.
- **Сайт в корне домена**: назови репозиторий `<твой-ник>.github.io` — тогда адрес будет `https://<твой-ник>.github.io/`.
- **Кэш браузера**: после правок жмёшь `Ctrl+F5`, иначе можешь смотреть старую версию (особенно на телефоне).
- **`.nojekyll` не нужен**: в проекте нет файлов/папок с нижним подчёркиванием в начале.
- **Кастомный домен**: `Settings → Pages → Custom domain`, потом DNS-запись `CNAME` на `<ник>.github.io`.
- Приватный репозиторий → Pages не отдастся на бесплатном аккаунте.

## Как добавить свой отзыв

В `index.html` найди массив `FACTS` и добавь строку по образцу:

```js
{"t":"БАГИ","r":"Смысловой перевод отзыва на русский. Сверху карточки — он.","o":"verbatim quote from the review","a":"Автор · 12 ч наиграно · 👍34"},
```

- `t` — ключ рубрики из массива `CATS` (`ТЕХСОСТОЯНИЕ`, `БАГИ`, `СЕТЬ`, `ГЕЙМПЛЕЙ`, `ОРУЖИЕ`, `ОТКРЫТЫЙ МИР`, `КОНТЕНТ`, `ИИ`, `ЦЕНА`). Нужна новая — допиши пару в `CATS` (ключ, подпись, эмодзи), она сама станет чипсом. Больше 9 рубрик ставить нельзя: клавиш `1`…`9` ровно девять.
- `r` — перевод, который видно сразу. Можно оставить `<em>подсветку</em>`.
- `o` — пруф-цитата **как есть** (её видно под переводом), `a` — подпись (ник, часы, лайки, язык в скобках).
- Вырезал кусок цитаты — поставь `[...]` на месте пропуска, чтобы никто не подумал, что автор так и написал.
- Счётчик в шапке (`#total`) и число в подписи рубрики пересчитываются автоматически.
- Двойные кавычки внутри текста лучше не ставить — бери «ёлочки», меньше экранирования.
- Если стимовская цензура `♥♥♥♥` попала в цитату — вырежи этот фрагмент или подсократи цитату: тест на такое ругается.
