# ДОЕБАТЬСЯ ДО ХУЙНИ — Gears of War: E-Day (ревью-рандомайзер)

Токсичный рандомайзер претензий к **Gears of War: E-Day**, собранный из реальных **негативных обзоров в Steam** (app `3010850`). Жмёшь кнопку — получаешь злой наброс по делу, а под ним **пруф**: цитата из обзора как есть и подпись (ник · часы на момент обзора · 👍). Англо-, польско-, испано- и китайскоязычные цитаты оставлены в оригинале: переводить их незачем, они и так бьют точно.

Родоначальник жанра, если что, был такой:

> «И это самое… Когда ждёшь у двери, которую нужно открыть секунд 30 или где-то даже минуту… мммм… 2005 год, охуенно»

## Что внутри

- **`index.html`** — весь сайт: HTML + CSS + JS в одном файле. Ноль зависимостей, ноль CDN, работает офлайн (открывается двойным кликом).
- **`validate.cjs`** — тест на Node.js (33 проверки: целостность базы и пруфов, отсутствие дублей и стимовской цензуры `♥♥`, ротация без повторов подряд, фильтр по рубрикам, счётчик, вывод и соответствие пруфа, случайность на 500 роллов, разметка и подвал).

### Управление

- **Кнопка «Накинуть дичи»** / `Space` / `→` / `Enter` — следующий наброс;
- цифры `1`…`9` — переключить рубрику, `0` — вернуть «Всё подряд»;
- **«👁 Пруфы: вкл/выкл»** — показать или спрятать цитату из обзора;
- **«Скопировать»** — наброс вместе с пруфом в буфер (с фолбэком через `execCommand`), **«Поделиться»** — системный шейр на мобилке.

## Пруфы и источники

Все цитаты пришли из блока негативных обзоров: <https://steamcommunity.com/app/3010850/negativereviews/> (тот же текст отдаёт JSON-эндпоинт `store.steampowered.com/appreviews/3010850?json=1&review_type=negative&language=...`).

- Цитата приводится **как есть** — с опечатками, caps и грамматикой автора. Это часть соли, править не надо.
- Где автор не подтверждён точно, в подписи стоит «негативный обзор Steam»; остальные подписаны ником, часами игры на момент обзора и лайками.
- Стимовская матерная цензура (`♥♥♥♥`) в базу не попала, чтобы не тащить в карточку мусорные символы.
- Обзоры «про повестку» сознательно не брали: тема сайта — техсостояние, оптимизация, геймплей, контент и цена.
- Ники — публичные данные Steam, приведены для указания источника цитаты. Не согласен с формулировкой — жми «Всё подряд» ещё раз, там 71 вариант.

## Локальный запуск

Просто открыть `index.html` в браузере. Если хочется как на сервере:

```powershell
cd c:\Projects\fact-randomizer
python -m http.server 8000   # или: npx serve .
# http://localhost:8000
```

Прогнать тесты (нужен Node.js):

```powershell
cd c:\Projects\fact-randomizer
node validate.cjs
```

Ожидаемый результат — `ВСЕ ПРОВЕРКИ ПРОЙДЕНЫ`.

## Деплой на GitHub Pages

### Вариант A — через сайт GitHub (без консоли)

1. Заходишь на github.com → **New repository**. Имя любое, например `gears-nagging`. Видимость — **Public** (Pages на бесплатном плане работает только для публичных репозиториев). **Create repository**.
2. **Add file → Upload files** → перетаскиваешь `index.html` (и `README.md`). **Commit changes**.
3. **Settings → Pages** (левое меню, раздел *Code and automation*).
4. **Source: Deploy from a branch** · **Branch: `main`**, папка **`/ (root)`** → **Save**.
5. Ждёшь 1–2 минуты, обновляешь страницу — сверху появится ссылка вида:
   `https://<твой-ник>.github.io/<имя-репозитория>/`
6. Открываешь, жмёшь кнопку, страдаешь у двери. Готово.

### Полезные нюансы

- **`index.html` должен быть в корне** (или в `/docs`, если выбрал такую папку в настройках Pages). Имя файла — строго `index.html`, иначе будет 404.
- **Сайт в корне домена**: назови репозиторий `<твой-ник>.github.io` — тогда адрес будет `https://<твой-ник>.github.io/`.
- **Кэш браузера**: после правок жмёшь `Ctrl+F5`, иначе можешь смотреть старую версию.
- **`.nojekyll` не нужен**: в проекте нет файлов/папок с нижним подчёркиванием в начале.
- **Кастомный домен**: `Settings → Pages → Custom domain`, потом DNS-запись `CNAME` на `<ник>.github.io`.
- Приватный репозиторий → Pages не отдастся на бесплатном аккаунте.

## Как добавить свои набросы

В `index.html` найди массив `FACTS` и добавь строку по образцу:

```js
{"t":"БАГИ","x":"Твой наброс. Поддерживается <em>подсветка красным</em> и «ёлочки».","q":"verbatim quote from the review","a":"Автор · 12 ч наиграно · 👍34"},
```

- `t` — ключ рубрики из массива `CATS` (`ТЕХСОСТОЯНИЕ`, `БАГИ`, `СЕТЬ`, `ГЕЙМПЛЕЙ`, `ОРУЖИЕ`, `ОТКРЫТЫЙ МИР`, `КОНТЕНТ`, `ИИ`, `ЦЕНА`). Нужна новая — допиши пару в `CATS` (ключ, подпись, эмодзи), она сама станет чипсом. Больше 9 рубрик ставить нельзя: клавиш `1`…`9` ровно девять.
- `q` — пруф-цитата, `a` — подпись (ник, часы, лайки). Наброс без пруфа покажется, но `node validate.cjs` такую строку забракует.
- Счётчик в шапке (`#total`) пересчитывается автоматически.
- Двойные кавычки внутри текста лучше не ставить — бери «ёлочки», меньше экранирования.
- Если стимовская цензура `♥♥♥♥` всё-таки попала в цитату — вырежи этот фрагмент или подсократи цитату, тест на такое ругается.
